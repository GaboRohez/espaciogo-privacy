# Privacidad de EspacioGo

Política pública de la aplicación Android EspacioGo.

- Responsable: Gabriel Rodríguez.
- Contacto: gabow95k@gmail.com.
- Página: https://gaborohez.github.io/espaciogo-privacy/
- Vigencia: 22 de noviembre de 2026.

Sitio HTML estático, adaptable a móvil, sin scripts ni recursos externos. Publicar la rama `main`, carpeta raíz `/`, mediante GitHub Pages. El código de la app se mantiene en un repositorio independiente.

La revisión del 22 de noviembre describe los datos locales, la cuenta del propietario en Firebase, los respaldos privados de Drive, las estadísticas opcionales, los avisos remotos y el identificador para soporte, la consulta de suscripción y la eliminación del perfil.

El contenido se mantiene en `POLITICA_PRIVACIDAD.md`. Ejecutar `python3 render_policy.py` actualiza el HTML conservando su estilo. Dentro del proyecto Android también sincroniza la copia documental y la página incluida para lectura sin conexión; no compila ni ejecuta la app.
